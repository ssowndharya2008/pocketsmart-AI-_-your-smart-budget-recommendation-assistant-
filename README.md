# PocketSmartAI

## Smart Budget and Recommendation Assistant

PocketSmartAI is a Generative AI project that helps users manage their budget and get smart recommendations.

### Features
- User Registration and Login
- Budget Planning
- AI Recommendations
- User Dashboard

### Technologies Used
- Python
- HTML
- CSS
- FastAPI
- Generative AI

### Project Goal
To help users manage their budget easily using AI.
